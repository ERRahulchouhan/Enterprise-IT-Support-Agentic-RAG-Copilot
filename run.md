# Run and Ingest Guide

This guide describes the current implementation in this repository. The code uses OpenAI for chat and embeddings, Pinecone for vector storage, and Tavily for optional web search.

## 1. Requirements

- Python 3.11 or newer
- An OpenAI API key
- A Pinecone API key and permission to create indexes
- A Tavily API key for web-search fallback (not needed just to ingest or answer from the private KB)

## 2. Set Up on Windows

Run these commands from the repository root in PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks virtual-environment activation, either permit scripts for the current user according to your organization's policy or use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

Create a `.env` file in the repository root. Do not commit it or put real credentials in this guide:

```env
OPENAI_API_KEY=your-openai-api-key
PINECONE_API_KEY=your-pinecone-api-key
TAVILY_API_KEY=your-tavily-api-key

PINECONE_INDEX_NAME=fde-it-support-rag
PINECONE_NAMESPACE=company-it-kb
EMBEDDING_MODEL=text-embedding-3-small
OPENAI_MODEL=gpt-4o-mini
TOP_K=4
MAX_RETRIES=1
ADMIN_API_KEY=replace-with-a-private-admin-key
```

`OPENAI_API_KEY` and `PINECONE_API_KEY` are required for sample ingestion. The OpenAI key is also required for chat. `TAVILY_API_KEY` is used only if the workflow falls back to web search. Index name, namespace, models, retrieval count, retries, and admin key have defaults in `app/core/config.py`; set them here to override those defaults. Keep `.env` private and rotate any credential that may have been exposed.

## 3. Ingest the Sample Knowledge Base

Ingest before running a private-KB demo:

```powershell
python .\ingest_sample_kb.py
```

The script reads the files immediately inside `data/sample_kb` (it does not scan subdirectories), loads them, chunks their contents, and writes the chunks to the configured Pinecone namespace. Supported document formats in the shared loader are PDF, TXT, Markdown, and DOCX.

The ingestion call chain is:

```text
ingest_sample_kb.py
  -> get_settings()
  -> load_file(path) for each file
  -> chunk_documents(all_docs)
  -> add_documents(chunks)
       -> get_vectorstore()
            -> ensure_index()
            -> get_embeddings()
            -> PineconeVectorStore(index, embedding, namespace)
       -> store.add_documents(chunks)
            -> embed each chunk and upsert its vector and metadata to Pinecone
```

`chunk_documents` uses `RecursiveCharacterTextSplitter` with 900-character chunks, 120-character overlap, and start-index metadata. Embeddings are not generated by a separate call in `ingest_sample_kb.py`: `PineconeVectorStore.add_documents()` calls the configured LangChain embedding object. `get_embeddings()` lazily creates `OpenAIEmbeddings` using `EMBEDDING_MODEL` (default `text-embedding-3-small`, 1536 dimensions). Pinecone is configured with cosine similarity.

The script prints the number of source files, chunks, and vector IDs returned by Pinecone. Ingesting again may create additional records because this script does not supply stable document IDs or delete old records first.

> **Important:** `ensure_index()` deletes and recreates the configured Pinecone index if its dimension does not match the selected embedding model. Deleting the index removes its existing vectors. Check the index and back up/re-ingest any needed data before changing embedding models or dimensions.

## 4. Run the Application

Start the FastAPI application from the repository root:

```powershell
python .\run.py
```

Open the UI at <http://127.0.0.1:8080/>. The interactive API documentation is at <http://127.0.0.1:8080/docs>, and the health endpoint is <http://127.0.0.1:8080/api/health>.

The `python run.py` entry point starts Uvicorn with reload enabled. The equivalent direct command is:

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --reload
```

## 5. How a Question Uses Embeddings and the Vector Store

For an IT support question, the main path is:

```text
POST /api/chat
  -> app.api.routes.chat()
  -> app.rag.workflow.ask(question)
  -> route_question()                 OpenAI chat model selects KB or direct response
  -> retrieve_kb()                    get_retriever().invoke(current_query)
  -> get_retriever()                  get_vectorstore().as_retriever(k=TOP_K)
  -> PineconeVectorStore              embeds the query and searches the configured namespace
  -> grade_kb()                       OpenAI chat model checks whether retrieved text is sufficient
  -> generate_from_kb()               answers from retrieved private documents when evidence is good
```

The retriever defaults to the four nearest chunks (`TOP_K=4`). The same embedding model must be used for ingestion and retrieval so query vectors and stored vectors have matching dimensions and semantics. If the private evidence is weak, the workflow uses Tavily, grades the web results, and may rewrite the query and retry, up to `MAX_RETRIES`. Greetings and casual messages can take the direct-answer path without retrieving documents.

## 6. Ingest Another Document Through the API

The app also exposes an authenticated upload endpoint. Start the server, then use `/docs` or send a multipart request. The `X-Admin-Key` header must match `ADMIN_API_KEY` in `.env`:

```powershell
curl.exe -X POST "http://127.0.0.1:8080/api/ingest" `
  -H "X-Admin-Key: replace-with-a-private-admin-key" `
  -F "file=@C:\path\to\document.pdf"
```

Supported suffixes are `.pdf`, `.txt`, `.md`, and `.docx`. The uploaded file is saved under `uploads/`, chunked, and added to the same Pinecone index and namespace used by the sample ingestion script.

## 7. Docker (Optional)

Build and run the container from the repository root:

```powershell
docker build -t enterprise-it-support-copilot .
docker run --rm -p 8080:8080 --env-file .env enterprise-it-support-copilot
```

Then open <http://127.0.0.1:8080/>. Run `python ingest_sample_kb.py` separately with the same `.env` before using private-KB answers, unless the index has already been populated.
